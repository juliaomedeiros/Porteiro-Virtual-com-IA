# Implementation Plan: Porteiro Virtual com IA

## Summary

O Porteiro Virtual com IA é uma solução modular para automação de portaria via WhatsApp, permitindo que moradores tirem dúvidas sobre o condomínio, solicitem 2ª via de boletos e realizem reservas de áreas comuns. A solução utiliza RAG (Retrieval-Augmented Generation) com Google Gemini para garantir respostas precisas baseadas nos documentos oficiais do condomínio, integrada via Evolution API (WhatsApp) e monitorada pelo LangSmith.

## Technical Context

**Language/Version**: Python 3.11+ (Backend), TypeScript 5+ (Frontend/Next.js)  
**Primary Dependencies**: FastAPI, LangChain or CrewAI (NEEDS CLARIFICATION), LangSmith, Evolution API (WhatsApp), PyMuPDF/Tesseract (NEEDS CLARIFICATION)  
**Storage**: PostgreSQL (Relational) + pgvector (Vector Storage)  
**Testing**: Pytest (Backend), Jest/React Testing Library (Frontend)  
**Target Platform**: Dockerized (Self-hosted/Cloud)  
**Project Type**: Web Service (Backend) + Web Application (Frontend)  
**Performance Goals**: < 10s response time (WhatsApp)  
**Constraints**: Guardrails robustos contra prompt injection, criptografia de dados sensíveis em repouso.  
**Scale/Scope**: MVP escalonável para múltiplos condomínios.
